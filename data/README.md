# Public source data

`raw/Metro_Interstate_Traffic_Volume.csv.gz` is the unchanged public dataset by
John Hogue (2019), **Metro Interstate Traffic Volume**, UCI Machine Learning
Repository: https://doi.org/10.24432/C5X60B

License: Creative Commons Attribution 4.0 International,
https://creativecommons.org/licenses/by/4.0/

Source: https://archive.ics.uci.edu/dataset/492/metro+interstate+traffic+volume

The project derives a deduplicated hourly series and historical lag features in
memory. The original compressed source is not edited. See `results/data_audit.json`
for cleaning counts and the file checksum.
